# /workflow: stages, entry points, workspace

Plan v3.1 §4.14 · [ADR 0004](../../docs/adr/0004-workflow-stages-and-workspace.md)

```
INTAKE → ARCHITECTURE → PLAN → DESIGN → IMPLEMENT → TEST → REVIEW → INTEGRATE* → RELEASE* → LEARN
 (docs)  (solution-level)  (epics/stories) (per story)                (* observed forge/CI events)
```

Users enter at **any** stage with whatever they already have, and stop at any stage. Gates
between the start and end stages are never skipped. *Stages* describe a piece of work's path.
*Build phases* (§2) describe the order the platform itself is built in.

| Skill | Role in the workflow |
|---|---|
| [adlc-conductor](adlc-conductor/SKILL.md) | `/adlc`: parse "from X to Y", preflight, run the stages with their gates, checkpoint, resume |
| [requirements-ingestion](requirements-ingestion/SKILL.md) | Primary entry: requirement documents → the sourced INTAKE document set |
| [workspace-resolver](workspace-resolver/SKILL.md) | Find, ask about or create the repos each stage needs (binding) |
| [stage-preflight](stage-preflight/SKILL.md) | SATISFIED / ADOPT / BACKFILL / ASK / BLOCK per required input (binding) |
| [brownfield-adoption](brownfield-adoption/SKILL.md) | Import tracker items, existing architecture and existing code; characterization mode |
| [repo-bootstrap](repo-bootstrap/SKILL.md) | New remote repo from a reviewed request; human or CI only |

The ARCHITECTURE stage is driven by
[engineering-design/architecture-package](../engineering-design/architecture-package/SKILL.md).

| File | What it is |
|---|---|
| [`stages.yaml`](stages.yaml) | The machine-readable stage graph: inputs, outputs, exit gates, roles, skills, repo roles, degraded mode |
| [`stages.schema.json`](stages.schema.json) | Its schema |
| [`schemas/`](schemas/) | `workspace-manifest`, `repo-request`, `intake-documents`, `checkpoint` |
| `lib/workflow_lib.py` | Shared helpers. Reuses the planning gates' YAML loader and schema validator. |

## Scripts (stdlib only)
| Script | Purpose |
|---|---|
| `requirements-ingestion/scripts/ingest_documents.py` | md / txt / html / Confluence / docx (pdf with `pypdf`) → anchored, hashed sections; register; `--diff` |
| `workspace-resolver/scripts/resolve_workspace.py` | Resolve repo roles; `--init-local`; `--request-remote` |
| `stage-preflight/scripts/stage_preflight.py` | Preflight a stage or range |
| `brownfield-adoption/scripts/import_tracker.py` | GitHub / Jira exports → `plans/inbox/` drafts |
| `repo-bootstrap/scripts/create_repo_from_request.py` | Render `templates/repo-bootstrap` and print or run the `gh` commands (human/CI) |
