For each stage, use the designated agent role:

- ARCHITECTURE: @architect — produce ADR with technology decisions, data model, module layout
- PLAN: @product-planner — decompose into epic/stories with typed acceptance criteria
- IMPLEMENT: @developer — build the CLI with all stories' ACs met, include unit tests
- TEST (design): @qa-derive — produce implementation-blind test design from ACs only
- REVIEW: @code-reviewer + @security-reviewer — parallel review of implementation

Requirements for Task Tracker CLI:
- REQ-001: Build a command-line task tracker
- Commands: add <description>, list [--status done|todo|all], done <id>, stats
- Storage: JSON file (~/.task-tracker/tasks.json)
- Each task has: id (auto-increment), description, status (todo/done), created_at, completed_at
- Stats shows: total, done, todo, completion percentage

Use MCP tools (record_evidence, record_handoff, etc.) at every stage transition.
Use worktree isolation for each agent.
Save all stage outputs to docs/.
